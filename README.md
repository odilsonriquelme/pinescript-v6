# pinescript-v6

Biblioteca de referência offline com a **documentação oficial do Pine Script v6**
(linguagem do TradingView), dividida em **8 partes em PDF**.

> ℹ️ Os arquivos **não são versões diferentes** da linguagem. `v6` é a versão do Pine Script;
> os números `.1` a `.8` são apenas as **seções** em que o manual foi dividido (por tamanho
> de exportação). Todos cobrem o mesmo Pine Script v6, cada um com tópicos diferentes.

## Índice das partes

| Arquivo | Temas principais |
|---|---|
| `PINESCRIPT V6.1.pdf` | Tipos e variáveis: `array`, `map`, `matrix`, `var`/`varip` |
| `PINESCRIPT V6.2.pdf` | Plotagem de barras/velas: `plotcandle`, `plotbar`, OHLC, `na` |
| `PINESCRIPT V6.3.pdf` | `request.security`, `indicator()`, `chart.point`, `color`, `line` |
| `PINESCRIPT V6.4.pdf` | Estratégias: `strategy.entry/exit`, `request.security_lower_tf`, `plot` |
| `PINESCRIPT V6.5.pdf` | `label`, `table`, `plotshape`, funções de tempo (`time`, `timestamp`) |
| `PINESCRIPT V6.6.pdf` | Estruturas de controle: `if`, `for`, `for...in`; arrays; `log.info` |
| `PINESCRIPT V6.7.pdf` | Estratégias (`strategy.exit`) e alertas: `alert()`, `alertcondition()` |
| `PINESCRIPT V6.8.pdf` | Estratégias avançadas: `strategy.close/entry`, variáveis forward/self-referenced |

*(Temas identificados pelos hyperlinks internos de cada PDF, que apontam para
`tradingview.com/pine-script-reference/v6/`.)*

## Uso

Consulta rápida offline durante o desenvolvimento de scripts Pine Script v6 no TradingView.
Conteúdo de referência estável (exportado da documentação oficial).
